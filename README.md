# OpenMaps

*See What's Ahead.* A United States-only, Android-first navigation app.

**Current state: Phase 1 (map foundation).** Real MapLibre map, live user location, recenter, compass, Map/Live toggle, search and settings placeholders. No routing, AR, parking, CV, AI or authentication.

- Setup, running, style configuration, device checklist: [docs/SETUP.md](docs/SETUP.md)
- Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Roadmap: [docs/ROADMAP.md](docs/ROADMAP.md)

> The Android/Compose/MapLibre code has not been compiled or run yet. Do the first build in Android Studio and work through the verification checklist in SETUP.md.
